# HOS — Health Operating System

שכבת הפעלה אישית המחברת בין האדם, הגוף והמערכת הרפואית.

## הרצה

```bash
npm install
npm run dev
```

פתחו את הכתובת ש־Vite מציג (ברירת מחדל `http://localhost:5173`).

## עקרונות

- Hebrew RTL, mobile-first (iPhone)
- נתונים נשמרים מקומית במכשיר (localStorage)
- אין אבחנה / מרשם / שינוי מינון / פסק הלכה
- יועצים (יורם, מיכל, הרב שטרן) מוצגים כ־Potential / Conceptual Advisors בלבד עד הסכמה מפורשת

## סטטוס דמו

טעינת דמו אוטומטית בביקור ראשון. ניתן לנקות ב־Settings → «נקה נתוני דמו».
